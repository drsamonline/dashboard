# dashboard — the live status of the drsamonline system

[![License: PolyForm Noncommercial 1.0.0](https://img.shields.io/badge/license-PolyForm%20Noncommercial%201.0.0-2e7d32)](LICENSE)

A **public** status page for the whole fleet, served from **GitHub Pages** (public
repo = free Pages, no paid plan). It shows every repo, its build health, its
download links, and the store.

## How it stays current (free, no PAT)

A static page cannot read private repos from a browser. So the data is
**pre-rendered**: the Forge agent (which has admin access) generates `data.json`
from the `registry`, the `knowledge` index and the GitHub API, and commits it here
on a schedule. `index.html` is a plain static app that just renders `data.json`.

```
registry + knowledge + GitHub API
        │  (Forge agent, scheduled)
        ▼
   data.json  ──▶  index.html  ──▶  GitHub Pages (public, free)
```

No PAT, no secrets, no server. Sensitive internals (quota detail, the commercial
plan) stay in the private repos and are reported to the owner directly, not here.

## Where it lives

**https://drsamonline.github.io/dashboard/play/** — that is the whole site.

The console is the app; there is **no landing page**, by design (`PAGES.json`:
`landing` is null, `app` is `docs/play/index.html`). So the site ROOT answers
**404**: `docs/` has no `index.html` and must not gain one. If you are looking at
a 404, you are one path short — add `play/`.

## Files

- `docs/play/index.html` — the console (no CDN, no build step).
- `docs/404.html` — the not-found page; its only link goes to the console.
- `data.json` — the rendered data (regenerated by the agent).
- `generate.py` — the reference generator the agent runs.
